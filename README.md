# Arena AI Desktop

Тестовое desktop-приложение для открытия [arena.ai](https://arena.ai/) в отдельном окне без браузера.

## Что внутри

- отдельное окно приложения для Arena AI;
- русское меню с командами "На главную", "Назад", "Вперед", "Обновить";
- открытие внешних ссылок в системном браузере;
- страница восстановления, если сайт временно не загрузился;
- сборка установочных файлов Linux через Electron Builder.

## Быстрый запуск для проверки

```bash
npm install
npm start
```

## Сборка тестового установщика

```bash
npm run dist:linux
```

Готовые файлы появятся в папке `dist/`. Для Linux собираются:

- `Arena AI-1.0.0-x64.AppImage` - portable-приложение, можно запустить без установки;
- `arena-ai-desktop_1.0.0_amd64.deb` - установочный пакет для Debian/Ubuntu.

## Примечание

Приложение показывает сам сайт `https://arena.ai/`, поэтому для работы нужен интернет и доступность сайта.
