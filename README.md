# Arena AI Desktop

Простое десктоп‑приложение на Electron для запуска [https://arena.ai/](https://arena.ai/) в отдельном окне, без браузера.

## Возможности

- Открывает `arena.ai` сразу в приложении.
- Удобное меню на русском: назад/вперед/обновить/домой.
- Один экземпляр приложения (повторный запуск фокусирует уже открытое окно).
- Экран ошибки с кнопкой "Повторить", если сайт временно недоступен.

## Запуск в режиме разработки

```bash
npm install
npm start
```

## Сборка установочного тестового приложения (Linux)

```bash
npm run dist
```

После сборки файл для установки появится в директории `dist/`:

- `Arena AI Desktop-<version>.AppImage`

### Установка/запуск AppImage

```bash
chmod +x "dist/Arena AI Desktop-1.0.0.AppImage"
./"dist/Arena AI Desktop-1.0.0.AppImage"
```
